# MarketCard AI

Telegram-бот для AI-обработки товарных изображений на Cloudflare Workers.

## Как работает

1. Пользователь отправляет фото товара.
2. Пишет свободным текстом, что нужно сделать с фото.
3. Бот отправляет фото + запрос в Cloudflare Workers AI (`FLUX.2 Klein 4B`).
4. Готовое AI-изображение возвращается в Telegram.

Примеры запросов:

- `Сделай премиальное рекламное фото косметики на бежевом фоне с мягким светом.`
- `Сделай карточку для Ozon, товар крупно, добавь текст: 120 мл, витамин C.`
- `Убери фон и поставь товар на белый мрамор, без текста.`

## Лимиты

- 5 бесплатных генераций.
- Подписка: 20 генераций на 30 дней.

## Инфраструктура

- Cloudflare Workers
- Cloudflare D1
- Cloudflare Workers AI
- Cloudflare Browser Rendering
- Telegram Bot API

Секреты не хранятся в репозитории.
